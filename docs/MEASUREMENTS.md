LCP element: the hand-drawn sketch in the hero (`/hero/sketch.png`, served as WebP by next/image). Observed (unthrottled) LCP breakdown in the trace: TTFB 14 ms, load delay 11 ms, load 9 ms, render delay 105 ms, about 140 ms in total. The simulated figure is dominated by the font and script bytes in flight at the same time (Fraunces upright 66 KB, Inter Tight 44 KB, JetBrains Mono 31 KB, React and page chunks about 150 KB). The site is static and will be served from Vercel's CDN with Brotli, which the local run does not model; real-device LCP should be well under the simulated number but has not been measured on a device.

Desktop preset, one run: performance 100, accessibility 100, best practices 100, SEO 100. LCP 0.7 s, TBT 0 ms, CLS 0.002.

What was done to get here, in order of effect:
1. Headline and sketch animate with transform only, never opacity, so Chrome counts them at first paint.
2. GSAP, ScrollTrigger and Lenis load by dynamic import after hydration; the hero's resting state is HTML and CSS.
3. Hidden hero layers (base, slats, tower, finished photo) mount only once GSAP is ready.
4. Fraunces italic replaced by a 25 KB lowercase subset, self-hosted; secondary fonts not preloaded.
5. Sketch stored without alpha (cream lines on black, blended with `mix-blend-mode: screen`) so next/image can serve a small lossy WebP instead of a 105 KB WebP with alpha.
6. Featured project images mount only when within 500 px of the viewport.

Other checks:
- Enquiry route: valid POST returns `{ok:true, delivered:false}` and logs the enquiry when `RESEND_API_KEY` is unset; invalid POST returns 400 with a message. **Delivery to the inbox not tested**: no Resend key is configured. Set the key in Vercel and send one test enquiry before launch.
- Structured data: LocalBusiness with three Reviews and an AggregateRating is emitted on the home page and parses as JSON. **Google's Rich Results test not run** (needs a public URL). Run it after the first deploy.
- Open Graph image: generated at /opengraph-image, 1200x630 PNG, from the pool house photo.
- Sitemap: 14 URLs (home plus 13 project pages). Robots: index when `NEXT_PUBLIC_SITE_URL` is set, otherwise noindex.
- Images: served by next/image as WebP (AVIF where the browser prefers it), blur placeholders generated by `scripts/blur.sh`.
- Screenshots of every section at 390 and 1440 px: `docs/screenshots/`.
- Generated hero video: one Seedance clip tried and rejected (not Antony's unit, 720p). Not shipped.

## After the video hero (13 Nov 2026)

Mobile, two runs: performance 90 / 89, accessibility 100, best practices 100, SEO 100. LCP 0.9 s (the poster frame), TBT 410 / 420 ms, CLS 0.046, Speed Index 1.7 / 1.6 s. The 720p film (1.8 MB) is the largest transfer; it loads only once the page is idle, so the poster is the first paint and decoding does not compete with hydration. Before that deferral the lab run showed TBT of 5.5 s from software video decoding, which is why the load is deferred. The reduced-motion and data-saver cases never load the film.
